How I worked

01

Go where the work happens

Watch operators at their stations before drawing a single screen. The real flow is rarely the documented one.

02

Design the whole lifecycle

A module never lives alone. I map how each step hands off to the next so nothing breaks between screens.

03

Build it, then write it down

I prototype in code and ship guidebooks alongside features, so teams can actually adopt what we make.
